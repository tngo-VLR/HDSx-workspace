# Planted-Error Audit

| Issue | Category | Why it matters | Corrected approach |
|---|---|---|---|
| The first candidate data path is a machine-specific Windows path. | Reproducibility | On a machine where that path exists, it can silently select a different file; on most other systems it is unusable. | Load the committed CSV using a repository-relative path and fail with a clear message if it is absent. |
| The comment says the data were downloaded fresh from NHANES last week. | Stewardship | That claim misstates the actual provenance and makes it unclear which snapshot produced the results. | Identify the prepared, cached course CSV and its CDC/NCHS public-use NHANES source; do not imply an unrecorded live download. |
| `Age > 20` and `Age < 80` exclude ages 20 and 80 even though the stated cohort includes them. | Correctness | The implemented cohort does not match the documented eligibility rule. | Use `Age >= 20` and `Age <= 80`, and show the cohort flow. |
| `na.omit()` removes a row for a missing value in any column, not only the variables needed for Table 1. | Correctness | This creates undocumented exclusions and can reduce or alter the cohort unnecessarily. | Report missingness for Age, BMI, and IncomeGroup first; retain the age-eligible cohort for that report, then exclude only missing BMI or IncomeGroup for the grouped table. |
| The table labels the second value as SD but calculates `var()` for BMI and age. | Correctness | Variance is in squared units and is not the standard deviation named in the output. | Calculate sample standard deviation with `sd()` and format the mean and SD consistently. |
| The interpretation claims statistical significance and says income determines BMI, although the code runs no significance test and the summary is observational/descriptive. | Interpretation | The text invents statistical evidence and makes an unsupported causal claim. | Describe only the observed unweighted group summaries; do not infer significance or causation from this table. |
| It says complete-case deletion makes the results complete and publication-ready. | Interpretation | Removing incomplete records does not establish that missingness is harmless, remove uncertainty, or make an unweighted classroom summary publication-ready. | State the missingness and exclusions, explain that the table is complete-case for BMI and IncomeGroup, and retain the classroom/descriptive limitations. |
